# أطلس جسم الإنسان ثلاثي الأبعاد • FATYAK 3D Human Anatomy Engine

- **المطور:** FATYAK
- **الترخيص والاستخدام:** مجاني بالكامل 100% ويعمل بدون أي مفتاح API أو اتصال بالإنترنت.

## طريقة التشغيل الفوري (بدون تثبيت أي برامج)
1. قم بفك الضغط عن الملف المحمّل.
2. افتح ملف **`index.html`** مباشرة في أي متصفح (Chrome, Edge, Firefox, Safari) على الكمبيوتر أو الهاتف.
3. سيعمل الموقع بكامل مميزاته الثلاثية الأبعاد والتسميات العربية وتخطيط القلب والنطق الصوتي فوراً!

## محتويات الحزمة الكاملة
- `index.html`: النسخة الكاملة المدمجة الجاهزة للتشغيل المباشر في أي متصفح بدون إنترنت.
- `fatyak-logo.svg`: الشعار الاحترافي الخاص بالمطور **FATYAK** بصيغة Vector SVG عالية الدقة.
- `src/organsData.js` (ونسخة في المجلد الرئيسي): قاعدة البيانات التشريحية العربية الشاملة لجميع الأعضاء والأجهزة الحيوية.
- `src/anatomyBuilder.js` (ونسخة في المجلد الرئيسي): محرك نحت وبناء جسم الإنسان والأعضاء الداخلية ثلاثية الأبعاد.
- `src/main.js` (ونسخة في المجلد الرئيسي): محرك العرض الثلاثي الأبعاد، الكاميرا، التسميات العربية، تخطيط القلب الحي، والاختبار التفاعلي.
- `src/styles.css` (ونسخة في المجلد الرئيسي): ملف التصميم الطبي الاحترافي باللغة العربية (`RTL`).
- `server.js` و `build.js`: ملفات تشغيل الخادم المحلي وإعادة البناء للمطورين.
